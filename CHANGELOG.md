# Changelog

## 0.1.0 — 2026-10-31

- Six additional book studies: hooked meander, hatched lozenges, tree headpiece,
  book frame, comb rosette and hooked rosette (twelve compositions total).
- Actual geometric hatching, fixed quarter-turn rosette construction and
  connected frame geometry with safe content insets.
- Natural square/rectangular recipe previews and complete SVG/JSON exports.

- Six new versioned book-inspired compositions with SVG/parameter examples.
- Public COMPOSITIONS/generateComposition API and optional React Composition.
- Russian/English playground, system language by default and saved manual choice.
- White specimen background, visible code, Alembic-style settings/preview layout.
- Removed navigation and ambiguous layout tabs; descriptive layout selector.
- Added composition raster/roundtrip tests and built-page language/layout checks.

- All 16 large motifs with original IDs, names, segments and fill polygons.
- Pure TypeScript ESM core, schema-v1 deterministic compositions and typed API.
- Motif, divider, band, repeatable grid/checkerboard tile, border/corner frame.
- Optional React components, SSR and container-resizing frames.
- Compact playground with gallery, presets, code copy and SVG download; original
  Hemingway 1 (Anders Norén, 2014) CSS, vendored with GPL-2.0 notices.
- Geometry, raster margins, repeat seams, layout, SSR and package consumer checks.
- MIT code and CC0 data. Initial local release candidate; not published.
