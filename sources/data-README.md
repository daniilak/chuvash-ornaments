# Chuvash patterns / Чувашские узоры

Координаты цифровых чувашских орнаментов из [редактора](https://daniilak.ru/pattern_editor).

**Лицензия: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)** — публичное достояние.
Можно копировать, менять и использовать как угодно, в том числе коммерчески, без разрешения и без указания авторства.

Мотивы основаны на традиционных чувашских орнаментах (в т.ч. по старым источникам).
Часть узоров собрана из других; юридически насчёт отдельных кусков автор может ошибаться, но намерение такое: это общее наследие.

Данные предоставляются «как есть», без гарантий.

## Что внутри

| Файл | Описание |
|------|----------|
| `patterns.json` | вся библиотека одним файлом |
| `index.json` | краткий каталог |
| `patterns/*.json` | каждый узор отдельно |
| `patterns.py` | то же для Python |

Сейчас в наборе **31** узоров.

## Формат

Ось Y направлена вверх (как в математике).

Сегмент (отрезок):

```json
[[x1, y1], [x2, y2]]
```

Заливка (многоугольник):

```json
[[x, y], [x, y], ...]
```

Пример:

```python
from patterns import PATTERNS

heart = PATTERNS["serdtse"]
print(heart["name"], len(heart["segments"]))
```
